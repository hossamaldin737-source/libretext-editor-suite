# سكربتات البناء | Build Scripts

## دليل استخدام السكربتات

### generate-file.ts — توليد ملفات جديدة

```bash
pnpm generate:file
```

**المدخلات:** المسار النسبي + المعرف الفريد + الهدف الرئيسي
**المخرجات:** ملف جديد بالترويسة العربية الإلزامية

---

### generate-header.ts — توليد الترويسة

```bash
pnpm generate:header
```

**المدخلات:** المسار النسبي للملف + المعرف + الهدف
**المخرجات:** ترويسة عربية مضافة إلى أعلى الملف (دون تغيير المحتوى)

---

### extract-line-numbers.ts — استخراج أرقام الأسطر (Regex)

```bash
pnpm extract:lines -- <path-to-file.ts> [--format=header|json|table]
```

**الوظيفة:** استخراج أرقام الأسطر الحقيقية لكل دالة/كلاس/method عبر regex.
**ملاحظة:** سرييع لكن قد يخطئ مع التوقيعات الممتدة على عدة أسطر.

---

### extract-line-numbers-ast.ts — استخراج أرقام الأسطر (AST) — الدقة 100%

```bash
pnpm extract:lines:ast -- <path-to-file.ts> [--format=header|json|table]
```

**المزايا:**

- كشف التوقيعات الممتدة على أسطر متعددة مع بيان نهايتها
- دمج Overloads تلقائياً مع بيان أماكنها
- كشف دقيق للـ Arrow functions ذات الـ Generics المعقدة
- كشف async, static, private, getter, setter, constructor

**التنسيق:**

- `header` (الافتراضي): جزء من الترويسة جاهز للصق
- `json`: مصفوفة JSON بجميع الرموز
- `table`: جدول Markdown

---

### update-indexes.ts — تحديث الفهارس التلقائي

```bash
pnpm update:indexes
```

**الوظيفة:** مسح جميع ملفات المشروع واستخراج الدوال/الكلاسات/الtypes وتحديث `SystemInventory.json`.

---

### work-monitor.ts — مراقبة صحة المشروع

```bash
pnpm work:monitor
```

**الوظيفة:** فحص الالتزام بالقواعد:

- **Rule 1:** تنبيه الملفات التي تتجاوز 400 سطر (تحذير فقط — الحد مفتوح حالياً)
- **Rule 2:** التحقق من وجود الترويسة العربية الإلزامية في كل ملف

---

## ملاحظات

- يجب تشغيل السكربتات من **جذر المشروع** فقط.
- جميع السكربتات تدعم TypeScript عبر `tsx`.
- جميع السكربتات تلتزم بالترويسة العربية الإلزامية.
