# سكربتات البناء | Build Scripts

## دليل استخدام السكربتات

### generate-file.ts — سكربت توليد ملفات جديدة

```bash
pnpm generate:file
```

**المدخلات:**
- المسار النسبي للملف
- المعرف الفريد (ID)
- الهدف الرئيسي

**المخرجات:**
- ملف جديد بالترويسة العربية الإلزامية

---

### generate-header.ts — سكربت توليد الترويسة

```bash
pnpm generate:header
```

**المدخلات:**
- المسار النسبي للملف الموجود
- المعرف الفريد (ID)
- الهدف الرئيسي

**المخرجات:**
- ترويسة عربية مضافة إلى أعلى الملف

---

## ملاحظات

- يجب تشغيل السكربتات من **جذر المشروع** فقط.
- يجب استخدام `tsx` لتشغيل ملفات TypeScript مباشرة.
- جميع السكربتات تitive الترويسة العربية الإلزامية.
